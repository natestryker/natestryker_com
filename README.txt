natestryker.com — personal website

PREVIEW LOCALLY
- Extract the full ZIP to a folder.
- Open the folder in VS Code.
- Use the VS Code Live Server extension, or run a local static server.
- Open index.html. Keep all folders/files in their original relative locations.

PAGES
- index.html             Homepage and hidden cursor link at lower right
- about.html             Nate's introduction, profile picture, and external links
- games.html             Game-Stuff: League history, clips, World of Tanks, and Foddian records
- creations.html         Three playable creations
- archive.html           Under Construction
- secret.html            Hidden page with only 'how did you find this'
- creations/*.html       Three game pages with common website navigation
- games/*/               Original standalone browser games
- media/league/          Two original WebM clips, MP4 playback alternatives, and preview images
- images/                Uploaded profile picture and favicon
- style.css              Website styles

IMPORTANT
- Creations open each game in a separate, embedded page; 'Open separately' launches the standalone version.
- All included games run in the browser; original game code has not been modified.
- Browser-local saved progress may be different across websites/domains.
- Riftcraft has a Manage save option to transfer progress.
- Some Riftcraft images use internet-hosted resources.
- The secret page isn't password protected; anyone with its URL can open it.
- Videos include both original WebM files and H.264 MP4 playback alternatives.

PUBLISH
- Publish the entire folder contents to a static web host such as GitHub Pages.
- Configure natestryker.com as your custom domain with the hosting provider.
- Check the games and videos on the final public URL before sharing it.
