What works here

Real conversions, with their limits made clear. Nothing is uploaded.

Included

  • Images: PNG, JPG/JPEG, WebP, BMP, GIF, SVG, TIFF and PNG-based ICO input. PNG, JPG/JPEG, WebP, BMP, TIFF and ICO output; PNG/JPG can also become single-frame GIFs. SVG is rasterized after removing scripts and external resources. Animation and multi-page TIFF are flattened to the first frame/page. JPG/WebP are lossy; JPG/BMP replace transparency with a chosen background. Metadata and embedded color profiles are removed.
  • PDFs: image pages (PNG/JPG/JPEG/WebP), ZIP of page images, selectable text, text HTML and text/metadata JSON; images to individual or combined PDFs; merge, split, select, reorder, omit, rotate, watermark and number pages. Text, Markdown, HTML and DOCX can become paginated plain-text PDFs. These text PDFs preserve content, not the original layout, images or formatting. The bundled font supports Latin, Greek and Cyrillic; unsupported characters produce an error.
  • Documents: TXT to escaped HTML/Markdown; Markdown to HTML/TXT; HTML to TXT/Markdown; DOCX to semantic HTML/TXT/Markdown. Word layout and some features are lost. Downloaded HTML is sanitized; it is never rendered as active content on this site.
  • Spreadsheets: CSV, TSV, XLSX and ODS to XLSX/ODS, CSV/TSV, JSON, HTML, XML, SQL inserts and simple text-table PDFs. CSV also exports to aligned TXT. CSV/TSV can become YAML or JSONL. Simple HTML tables can become CSV/XLSX. Multi-sheet exports create one output per sheet where necessary. Text exports use cached formula results and do not calculate formulas. CSV/TSV imports preserve cell text, including leading zeros. Workbooks may lose styles, charts and features when changing formats.
  • Data: JSON, YAML, TOML, XML, JSONL/NDJSON and INI, restricted to data the destination can represent. Flat record/row arrays can become CSV/TSV/XLSX/SQL. CSV/XLSX can create SQLite databases; SQLite user tables can export to CSV/JSON/XLSX. INI is restricted to strings and one section level. TOML cannot represent null. JSONL requires an array. Structured XML output uses a typed schema to retain JSON types; ordinary XML maps attributes to @names and text to #text. SQLite creation uses text columns; exports reject binary BLOBs.
  • Audio: browser-local FFmpeg decoding for MP3, WAV, Ogg Vorbis/Opus, FLAC, AAC/M4A, AIFF, WMA and AMR where their codecs are supported. Outputs: MP3, WAV, Ogg Vorbis, FLAC, AAC/M4A and AIFF. Includes clipping, bitrate/sample-rate/channel changes and optional loudness normalization. Lossy re-encoding reduces quality; lossless output cannot restore lost source detail. Tags are copied where possible, but artwork and container-specific tags may be lost.
  • Video: supported MP4, WebM, MOV, MKV, AVI, FLV, WMV, MPEG, M4V, 3GP, OGV and TS inputs to MP4/WebM/MOV/MKV/AVI. MP4/MOV/MKV output uses H.264/AAC, WebM uses VP8/Vorbis and AVI uses MPEG-4/MP3. Includes extracting audio, GIFs, thumbnails, frame sequences, removing audio and resizing/compressing to MP4. GIF can become MP4. Video is re-encoded; subtitles and extra tracks are not retained. Actual tracks are checked before audio/video options are shown.
  • Archives: ZIP, USTAR TAR and TAR.GZ/TGZ conversion/extraction; GZIP compression/decompression; ZIP packaging of original or converted files. File bytes and safe relative paths are retained. Links, encrypted ZIPs, ZIP64, non-UTF-8 ZIP filenames, multi-volume archives, unsafe paths and unsupported TAR records are rejected. Files are never opened or executed.

Limits

100 input files and 150 MB total. Media: 64 MB per file, up to 20 minutes of audio or 5 minutes of video per conversion; use clip settings for longer source files. GIF output is limited to 30 seconds. Text/markup: 5 MB. Images: 16 megapixels. PDF page operations: 100 selected pages; merging: 500 pages. Extracted archives: 150 MB / 500 entries. Frame export: 200 frames. Total outputs: 200 MB / 500 files. Short clips and small batches work best on phones.

Media encoding runs in a single-thread worker, so it needs no special cross-origin headers. It is slower than desktop software. Cancel terminates the worker and releases its memory; completed batch outputs remain downloadable. Nothing is saved to this site.

Skipped from the requested list

These options are omitted from the converter catalog. They require additional format engines, a full layout/synthesis system, or further validation to offer reliably:

  • Specialist image formats: AVIF encoding/decoding, HEIC/HEIF, TGA, PPM/PGM/PBM, QOI, PSD, EXR/HDR, DDS, KTX2 and camera RAW.
  • Image tracing and animation workflows: PNG/JPG to traced SVG; APNG/GIF and animated WebP/GIF conversion; sprite-sheet extraction and creation. Static exports of GIF/WebP preserve only the first frame.
  • PDF layout reconstruction: PDF to DOCX/EPUB/PPTX/XLSX/SVG; EPUB to PDF; Word to PDF with original layout; HTML/Markdown to PDF with original visual formatting. Included DOCX/HTML/Markdown PDF exports are explicitly plain text.
  • OCR and encryption: scanned PDF to TXT/searchable PDF, password protection/removal, and PDF compression. Passwords can only be supplied for PDF text/image exports; PDF editing rejects encrypted files.
  • Other document formats: RTF, legacy DOC, ODT, Apple Pages and LaTeX workflows; HTML to DOCX and other DOCX/ODT/RTF cross-conversions.
  • Advanced data: Parquet and Apache Arrow.
  • Additional audio work: MIDI synthesis, explicit ALAC encoding, Opus encoding and merging audio files. Opus output was excluded after it failed a real browser encoding check. Existing ALAC-in-M4A input may decode through FFmpeg; lossless ALAC output is not advertised.
  • Additional video work: animated WebP/APNG output, VP9/H.265/AV1 output, dedicated frame-rate conversion and rotation tools. Re-encoding to H.264 is available only for input codecs the bundled engine can decode.
  • Other archives: RAR, 7Z, BZ2 and XZ, plus PAX/GNU TAR extensions and encrypted/multi-volume archives.

Plain TXT and Markdown are not treated as different formats by renaming an extension: TXT to Markdown escapes content into actual Markdown. Likewise, media is actually encoded and containers are actually rebuilt.
